# 详情页翻新

从商品编码登记旧长图、透明瓶图、运营资料和正式标志，生成分屏计划和 PNG 审稿。预览保留逐屏来源和缺项，按同一版本提供前后对照。已确认稿可复用。可编辑成稿在画面确认后制作。

## 入口和依赖

日常使用 [统一工作台](../README.md)。需要独立联调 v2 时，在明确的 E 盘数据目录和独立端口设置好 `REFRESH_V2_DATA`、`REFRESH_V2_ASSETS`、`REFRESH_V2_PORT` 与 `REFRESH_PHOTOCRAFT`，然后运行 `python -B refresh_service.py`。依赖为 Python 3.12、`requirements.txt`、PhotoCraft CLI 0.22.0 与模板所需的授权字体。旧版 `app.py` 的独立入口仍需要本机 `data/<商品编码>.json`。真实商品计划和素材由部署方提供。

v2 按商品编码目录扫描旧图、运营表、瓶图及品牌标志。统一工作台默认在 `DETAIL_ASSET_ROOT` 的 `产品编码测验` 子目录下发现这些资料。独立或覆盖配置时用 `REFRESH_V2_ASSETS` 指向包含商品编码子目录的资料根。

## 运行路径

- `local_review` 使用本地分屏和排版。已冻结的素材用 `reuse` 继续审稿。
- `protected_sunburst` 按本机登记的提示词和冻结参考调用公司 `/v1/images/edits`，用本地保护合成生成首屏候选和对照图。若暂时没有可用回图，页面显示冻结首屏及网关状态。
- 公司分屏和场景生成需要各自的授权范围。已授权的模型能力、调用状态、任务恢复和下载接口见 [翻新 API](REFRESH_API.md)。

默认演示无需公司网关。企业接入仅由部署人员通过服务器环境和私有配置进行。提交原请求查单时使用任务回执内的请求标识。
